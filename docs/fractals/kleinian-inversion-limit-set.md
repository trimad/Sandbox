# Kleinian Inversion Limit Set

## Summary

Kleinian and Schottky limit sets come from iterating Möbius transformations and circle inversions. This note catalogs the first implementation as a compact Kleinian-inspired inversion study rather than a full Indra's Pearls group-word renderer.

![Rendered Kleinian Inversion Limit Set](../../output/fractals/KleinianInversion/KleinianInversion.png)

## Formula / Rule

Circle inversion in the unit circle can be written:

$$z\mapstorac{1}{ar z}=rac{z}{|z|^2}$$

A Möbius transformation has the form:

$$z\mapstorac{az+b}{cz+d}$$

Current renderer uses a bounded fold/inversion loop:

1. Reflect into a symmetric quadrant.
2. Invert points inside the unit circle.
3. Translate/fold into a neighboring circle-pair region.
4. Use iteration count and minimum radius as the field value.

## Mathematical Background

A Schottky group is generated by Möbius transformations that map paired circles inside/outside one another. Repeated group words produce nested limit sets. This is a deeper direction than standard escape-time fractals and should be expanded into a proper group-word renderer.

## Rendering Method

The current C# implementation performs per-pixel inversion/folding iterations and shades the resulting field. It is an exploratory distance/escape proxy, not yet a mathematically complete Kleinian group renderer.

## Parameters

- CLI keyword: `kleinian-inversion`
- Rendered preset: `width=384 height=384 min-real=-2.5 max-real=2.5 min-imaginary=-2.5 max-imaginary=2.5 bailout=160 highest=50`
- Shader: `log1p-mapped`

## Coloring Techniques

Field shading works, but a mature version should render limit points, circle packings, and tessellations with group-word depth coloring.
